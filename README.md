# 🌐 ForumFlow

**ForumFlow** is a modern full-stack **MERN (MongoDB, Express.js, React, Node.js)** based community discussion platform — inspired by Reddit & Quora — where users can create posts, share ideas, ask questions, and engage through comments and votes.

---

## 🚀 Features

- 🧑‍💻 **User Authentication** (JWT + Firebase/Custom)
- 🗨️ **Create, Edit & Delete Posts**
- 💬 **Comments **
- 👍 **Upvote / Downvote System**
- 👑 **Role-based Access** (User & Admin)
- 🔍 **Search and Filter Posts**
- 📱 **Responsive Design** with Tailwind CSS
- ⚡ **Protected Routes** for secure pages
- ☁️ **Deployed on Vercel & MongoDB Atlas**

---

## 🧩 Tech Stack

| Category | Technology |
|-----------|-------------|
| Frontend | React, Tailwind CSS, React Router, Axios, React Query |
| Backend | Node.js, Express.js, JWT |
| Database | MongoDB (Mongoose) |
| Deployment | Vercel (client) & Render / Railway (server) |
